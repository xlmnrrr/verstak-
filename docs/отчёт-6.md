# Отчёт этапа 6 «Производство»

> 12.11.2026. Проверки: `scripts/проверка-6.cjs` (5 из 5, ~1 мин), `npm test` 309, `tsc` чисто.

## Сделано
- **Модель** `src/model/производство.ts`: спецификация модулей, деталировка (деталь, размеры, толщина, количество, материал, кромка по четырём сторонам), расход (листы ЛДСП 2750 × 1830 по толщине плиты, ХДФ, кромка по толщине). Живая смета в нижней панели считается из того же `детали()`.
- **Экспорт** `src/export/`: **PDF** (A4 альбомная, рамка и штамп «Заказ № · Дата · Клиент · Дизайнер» на каждом листе, план помещения с выносками размеров и нумерованными изделиями, спецификация, расход и кромка, деталировка; печать скрытым окном Electron); **XLSX** (три листа: деталировка, спецификация, расход; собирается без библиотек через zip из `three/examples/jsm/libs/fflate`); **CSV** (`;`, UTF-8 с BOM, для программ раскроя); **glTF** (`.glb`: изделия из тех же примитивов, что рисует 3D, плюс стены).
- **«Чертёж PROSTO одним кликом»**: кнопка в окне «Экспорт» (поля штампа запоминаются).

| Что | Результат |

| Автотест «деталировка = 3D» | для каждого корпусного, столового и мягкого изделия каталога (больше 40) плиты в деталировке совпадают с плитами в 3D по размерам |
| Автотест «не режет и не теряет» | число деталей = сумме по экземплярам; листы, кромка и ХДФ совпадают со сметой; ни одна деталь не больше листа |

| Время выгрузки | CSV 121 мс, XLSX 106 мс, glTF 62 мс, PDF 369 мс |
| Консоль | ошибок нет |
