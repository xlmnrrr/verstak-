# Отчёт этапа 1Б-2 «Все экраны и мастер помещения»

> 12.11.2026. Проверки: `scripts/проверка-1Б2.cjs` (22 из 22, ~2 мин), `npm test` 305, `tsc` чисто, один замер.

## Сделано
**Правки по стилю:** (1) превью проекта снимается при «Сохранить» и при автосохранении (IPC `проекты:превью`, только для уже сохранённых проектов); (2) длинные имена на листах: подсказка при наведении + перенос в штампе, в карточках проектов — до 2 строк и `title`; (3) мини-карта комнаты в углу сцены (контур и следы изделий, выбранное — латунью); (4) контраст границ: новый токен `--граница` (≥ 3:1 на всех поверхностях обеих тем), применён к кнопкам, полям, чипам; (5) кнопка «Свернуть свойства» и язычок «Свойства» (объект остаётся выделенным и не уходит под панель).

**Экраны и окна:** первый запуск (выбор темы + тур из 3 шагов, «Пропустить»); список проектов (сетка с превью, поиск, сортировка, удаление с подтверждением, четыре состояния); мастер помещения с тремя способами — размеры, контур Г/П (вырез задаётся числами, контур рисуется рядом), «квартира по сетке» (клетка 300/500/600/1000 мм, закраска мышью, помещения-кисти, автодвери между соседями → `квартираПоСетке`: общие стены, проёмы); пять помещений заказчика одним кликом; вкладки помещений и «План квартиры» (SVG, клик — переход); каталог (поиск по названию и габаритам «шкаф 600», фильтр по помещению и категории, недавние, избранное, карточка с габаритами и значком вида); свойства по группам; материалы (поиск, избранное, пипетка `EyeDropper`, свой цвет, ряд своих цветов); окна «Проверки» (список, клик — переход к изделию), «Настройки» (тема, фон сцены, шаг сетки, сетка, толщина плиты, автозапуск Windows, горячие клавиши), «Справка» («собрать кухню за 15 минут», клавиши, тур заново), «Экспорт» (описание форматов; рабочие PDF/XLSX/CSV/glTF — этап 6).

**Память интерфейса** (`localStorage`): каталог, свёрнутые свойства, недавние и избранное, свои цвета, тема, тур. Клавиатура: Tab/Enter/Esc, фокус-кольцо 2 px; Esc закрывает окно, план, каталог, затем снимает выделение.

## Отступления и решения
- Каталог теперь из модели v2 (82 изделия), а не из каталога v1; добавление по `id` работает через таблицу.
- Двери в сетке ставятся автоматически в первой общей стене пары; ручное размещение дверей и окон — позже.
- «План квартиры» — плоская схема (2D), не 3D-вид; переход по клику в 3D-режим помещения.
- Видно только активное помещение в 3D (как в 1А-2).
- Автозапуск Windows подключён через IPC, в проверке не вызывался.
