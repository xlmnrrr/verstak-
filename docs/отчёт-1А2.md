# Отчёт этапа 1А-2 «Рендер и скорость»

> 11–12.11.2026. Реализация по `docs/рендер.md` §10. Все цифры «замер» — окно Electron, GTX 1650, 1920×1080 (эмуляция вида), dpr 1, профиль «высокое» (выбран «авто» по имени видеокарты), состав «интерфейс» (с полками и ящиками), тени пересчитываются **каждый кадр** (`ЗАМЕР_ТЕНИ=каждый-кадр`). Исходные файлы: `проверка/замер-electron-интерфейс-каждый-кадр-*.json`, `проверка/замер-итог-*.txt`.

## 1. Сделано
- **Новый рендер** `src/render/`: сборщик сцены (экземпляры → слоты `InstancedMesh`, diff по ссылкам), общие геометрии, шейдер плиты (размер в `aSize`, шейдерная фаска, цвет торца: кромка / «сырая» ЛДСП), настоящая фаска вблизи (LOD по расстоянию, гистерезис), тени по событиям (`autoUpdate = false`, камера тени по границам сцены), `frameloop="demand"` и одна `попроситьКадр()`, профили качества и «авто», камера «Сверху / Прогулка», стрелки постоянного размера в экранных координатах, автомат жестов, выбор по габаритам. `Scene.tsx` и `Furniture.tsx` удалены.
- **Пять багов:** вставка модуля (`найтиМесто` по следам с поворотом и контуру); `Ctrl+Z` правки цифрой (команда без пустых записей, отмена из числового поля, выделение после отмены сохраняется); формы Г и П в 3D (`model/стены.ts`, стены и проёмы из контура); «влезает» (`model/проверка.ts`, красный контур одной линией + метка с цифрой в мм); модуль шире комнаты (не прыгает, выступ не растёт). Плюс баг стрелки «вверх» из v1 (§8 рендера).
- **Пример кухни починен:** мойка и варочная панель больше не пересекаются (варочная сдвинута на 200 мм над своей плитой) — `src/lib/демо.ts` и `public/Библиотека/пример-проекта.kitchen`; тест «пример открывается с нулём конфликтов».
- **Живой прогон v1-бэкапа** на настоящей папке `Проекты\` (п. 3 ниже).
- **Сборка .exe** nsis + portable в `release/`; найден и исправлен баг portable: данные лежали бы во временной папке распаковки (теперь рядом с .exe, `PORTABLE_EXECUTABLE_DIR`).

## 2. Как проверить руками
1. `npm run dev`, затем `npx electron .` (с `КУХНЯ_DEV_URL`), либо запустить `release\win-unpacked\Верстак.exe`.
2. «Пример кухни»: ЛКМ по шкафу — тащить; стрелки: схватить зелёную за любое место — идёт строго вверх; G / T / R — двигать / растянуть / крутить; Esc во время жеста — откат.
3. Вкладка «Объект»: набрать ширину цифрой, `Enter`, `Ctrl+Z` — размер вернулся, модуль на месте.
4. «Конструктор»: добавить 10 тумб подряд — встают вдоль стен лицом в комнату; «Шкаф 3-дверный 2843» в комнате 2000 — красный контур и «⚠ 422 мм».
5. Мастер комнаты не умеет Г/П (это 1Б-2); Г и П проверены кодом проекта (скриншоты ниже).
6. Автопроверки: `node scripts/проверка-1А2.cjs <адрес dev>` (22 проверки), `node scripts/замер.cjs electron`, `node scripts/проверка-v1-живьём.cjs`, `node scripts/проверка-exe.cjs <exe>`.

**fps упирается в частоту экрана** (~280 Гц, 3,57 мс): кадр GPU не больше 3,57 мс, точнее замер не покажет. Судить по мс кадра и CPU рендера.

### Эмуляция слабого ноутбука, `ЗАМЕР_CPU=4` (тот же стенд; GPU CDP не замедляет, значит эмулируется только процессор)

| GTX 1650 | 46,6 fps | 280 fps (предел экрана); кадр 21,5 → 3,57 мс |

### Прочее
- Сценарий «перетаскивание» (300 кадров, команда как мышью, тени живые): GTX 1650 — 211,6 fps, шаг 2,9 мс; `ЗАМЕР_CPU=4` — **35,3 fps, шаг 14,35 мс** (запас над 30 небольшой; в приёмку не входит; главный подозреваемый — перерисовка панелей React, §11 п. 13 рендера — не трогали).
- Сборка сцены (диф и запись буферов): 3,8–11,4 мс на GTX, 88 мс при CPU ×4 (кэш `детали()`).
- Простой: за 2 с кадров 0–1 (demand работает). Самопроверка «авто»: медиана кадра 3,6 мс → профиль «высокое».
- Состав сцены: 7 draw calls = плита, цилиндр, стены, пол, сетка (+ плита и цилиндр в проходе тени); на примере 12–13 (+ конус, сфера, стекло, контур, стрелки).
- Тесты: `npm test` — 302 пройдено, 2 пропущено (были 237+); `npx tsc --noEmit` — без ошибок. Проверка в окне Electron `проверка-1А2.cjs`: **22 из 22**; ошибок шейдера в консоли нет (скрипт замера падает на Shader Error, код 3).

## 4. Отступления от `docs/рендер.md` (с причиной)
1. `PCFSoftShadowMap` в three 0.187 удалён → `PCFShadowMap` + `shadow.radius` (§4.1 допускал).
2. Предел группы 16 384 инстансов без второго меша: буфер просто растёт ×2 (500 модулей ≈ 8 тыс. деталей, предел не достигнут).
3. «Слабый ноутбук» во время жеста: тени пересчитываются раз в 250 мс вместо пятна-заглушки (проще, без «призрака»; на этой машине профиль не включался — не проверено).
4. Уплотнение групп (`уплотнить()`) написано, но в простое пока не вызывается.
5. Стрелки «растянуть» начинаются в центре +грани и идут по локальным осям; «крутить» показывает только Y; у стрелок для нескольких выбранных — по комплекту на каждый объект.
6. Лампа светильника без свечения (нет emissive в атрибутах инстанса); отражения `RoomEnvironment` с силой 0,18 одного размера для высокого и среднего.
7. Показывается только активное помещение (как §1.2 п. 7), переключение — пересборка.
8. Добавлено вне документа: `Ctrl+Z` из числового поля, выделение после отмены, нулевая правка цифрой не создаёт запись, `PORTABLE_EXECUTABLE_DIR`, сборка в `release\` (иначе мешала папке `dist` Vite), тест миграции учитывает уже мигрированные файлы.
