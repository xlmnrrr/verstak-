# DESIGN.md — «Верстак»

> Токены до вёрстки (`ДИЗАЙН-БРИФ.md` §5). Этап 0, 11.11.2026. Живой образец: `docs/превью/стиль.html` (открывается без интернета).
> Всё, что ниже, переносится в `src/ui/design/tokens.css` на этапе 1Б-1 один к одному.

## 1. Идея

Мастерская и чертёж в одном. Там, где человек работает руками (кнопки, выделение, ручки управления), — тёплое дерево и латунь. Там, где важны размеры, — тонкие чертёжные линии, засечки и синие выноски, как на листе с замером. Инструмент тяжёлый, точный и тихий: ничего не блестит без причины, а каждое число стоит ровно.

**Одна смелая вещь — «листы».** Проекты, экспорт и печать оформлены как чертёжные листы с рамкой и **штампом** в правом нижнем углу (Заказ № · Дата · Клиент · Дизайнер). Мастер узнаёт свой язык (PROSTO, ГОСТ-рамка), клиент видит серьёзную работу. Всё остальное спокойное и дисциплинированное.

**Чего здесь нет намеренно:** одинаковых карточек-плиток на пустом фоне, градиентов-подложек, эмодзи, капса над заголовками, «→» в кнопках, кремового фона с терракотой, почти-чёрного с кислотным акцентом.

## 2. Цвет

Две темы **равноценны**. Выбор при первом запуске: «Мастерская», «Калька» или «Как в Windows».

| Токен | Роль | Мастерская (тёмная) | Калька (светлая) |
|---|---|---|---|
| `--фон` | окно, обложка | `#1E1914` тёмный орех | `#E8ECEA` чертёжная плёнка |
| `--поверх-1` | панели | `#262019` | `#F5F7F6` |
| `--поверх-2` | поля, вложенные блоки | `#2F281F` | `#DFE4E1` |
| `--поверх-3` | наведение, выбранная строка | `#3A3126` | `#D2D9D5` |
| `--линия` | границы, разделители | `#4A3F32` | `#B8C1BC` |
| `--текст-1` | основной | `#F3ECE1` | `#142019` |
| `--текст-2` | вторичный, подписи | `#C7BBA9` | `#36443D` |
| `--текст-3` | подсказки, отключённое | `#AC9F8C` | `#4C5952` |
| `--латунь` | действие, выделение, фокус | `#D9AD5F` | `#704D0E` |
| `--на-латуни` | текст на латунной кнопке | `#1E1408` | `#FFFFFF` |
| `--синька` | размерные линии, выноски, замеры | `#86B9EA` | `#174B8A` |
| `--опасно` | «не влезает», удаление | `#F2846C` | `#982E1A` |
| `--готово` | «влезает», сохранено | `#8CC28A` | `#2A5B2C` |

**Контраст (WCAG, проверено расчётом):** каждый цвет текста, латунь, синька, «опасно» и «готово» дают **≥ 4,9:1 на всех четырёх фонах** обеих тем. Худшая пара: `--текст-3` на `--поверх-3` в Мастерской — 4,91. Латунная кнопка: 8,7 (тёмная) и 7,6 (светлая).

Фон 3D-сцены — отдельная настройка (8 пресетов + свой цвет), с темой интерфейса не связан.

## 3. Шрифт

| Роль | Шрифт | Где |
|---|---|---|
| Интерфейс, заголовки, текст | **Onest** (переменный, 400–700), OFL | везде |
| Размеры на сцене и в выносках | **JetBrains Mono 500**, OFL | только чертёжный слой: выноски, рулетка, цифра у курсора |

Числа в полях свойств — Onest с `font-variant-numeric: tabular-nums`: колонки миллиметров стоят ровно без моноширинного шрифта.

**Шкала:** 12 / 13 / 15 / 18 / 24 / 32 и 56 для обложки. Межстрочный 1,45 (текст), 1,15 (заголовки). Насыщенность: 400 текст, 560 подписи групп и кнопки, 680 заголовки. Капс не используем; подписи групп — обычный регистр, 13 px, `--текст-2`.

Файлы: `woff2`, подмножества кириллица + латиница, лежат в приложении. Внешних запросов нет.

## 4. Пространство и форма

- **Отступы:** 4 / 8 / 12 / 16 / 24 / 32 / 48.
- **Радиусы по смыслу, а не один на всё:** 6 — поля ввода, 10 — кнопки, 14 — панели, 20 — модальные окна. Листы проектов — **2** (это бумага).
- **Тени:** три уровня, мягкие, тёплого тона в Мастерской и холодного в Кальке:
  - `--тень-1` панель: `0 1px 2px rgb(0 0 0 / .25)`;
  - `--тень-2` всплывающее: `0 8px 24px -8px rgb(0 0 0 / .45)`;
  - `--тень-3` модальное: `0 24px 64px -16px rgb(0 0 0 / .55)`.
  В Кальке те же с прозрачностью `.08 / .16 / .22` и оттенком `rgb(20 40 30 / …)`.
- **Цели:** не меньше 32 × 32 px, главные кнопки 40 px.

## 5. Иконки

Свой SVG-спрайт: сетка 24, линия 1,5 px, скруглённые концы и стыки, без заливок (кроме точки «активно»). Общие формы — по мотивам Lucide 1.62.0 (ISC), мебельные (купе, полка, штанга, ящик, подъёмник, петля, ниша, рулетка) рисуются в той же сетке. Цвет — `currentColor`.

## 6. Движение

150–200 мс, только `transform` и `opacity`, кривая `cubic-bezier(.2,.7,.2,1)`. Движение отвечает на действие: панель выезжает, «островок» действий проявляется над выделенным, лист проекта приподнимается на 2 px при наведении. Один постановочный момент на всё приложение — медленный облёт 3D-сцены на обложке. `prefers-reduced-motion` отключает облёт и сдвиги.

## 7. Раскладка

**Обложка:** вся площадь — живая 3D-сцена (пример или последний проект), облёт камерой. Слева колонка 360 px: название, одна строка о том, что делает приложение, четыре действия списком инструментов (иконка + глагол + горячая клавиша). Снизу полоса последних проектов — листы со штампом. По центру ничего не стоит: смотрим на комнату.
```
┌────────────────────────────────────────────────────────────┐
│ Верстак                         (3D-сцена на весь экран)   │
│ Мебель по размерам помещения                               │
│                                                            │
│ ▢ Новый проект           N                                 │
│ ▢ Открыть проект         Ctrl+O                            │
│ ▢ Открыть файл           Ctrl+Shift+O                      │
│ ▢ Пример                                                   │
│                                                            │
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   Последние            │
│ │ лист │ │ лист │ │ лист │ │ лист │                        │
│ └штамп─┘ └штамп─┘ └штамп─┘ └штамп─┘                        │
└────────────────────────────────────────────────────────────┘
```
**Редактор:** сцена занимает всё. Слева узкая полоса инструментов 56 px; каталог выезжает из неё (клавиша `P`) поверх сцены на 320 px и сам уходит, когда тащишь изделие в комнату. Справа свойства 320 px, свёрнуты, пока ничего не выбрано. Снизу строка 44 px: инструменты слева, живая смета и проверки справа. Над выделенным объектом — «островок» из 5 действий.
```
┌──┬───────────────────────────────────────────────┬─────────┐
│▢ │ Кв. 160 [Гардеробная][Прихожая][+]  Сохранено │Свойства │
│▢ │                                               │ Размеры │
│▢ │          [ островок действий ]                │ Положен.│
│▢ │              ┌──────┐  1910                   │ Наполн. │
│▢ │              │ шкаф │◄────►                   │ Фасад   │
│  │              └──────┘                         │ Материал│
├──┴───────────────────────────────────────────────┴─────────┤
│ Двигать Растянуть Крутить Рулетка │ 3,2 листа · 41 м кромки │
└────────────────────────────────────────────────────────────┘
```
Выравнивание текста — по левому краю везде, кроме чисел в колонках (по правому).

## 8. Язык интерфейса

Глаголы по делу, обычный регистр, без восклицаний. Кнопка и результат называются одинаково: «Сохранить» → «Сохранено». Ошибка говорит, что случилось и что делать: «Шкаф 2843 не входит: до стены 2400, не хватает 443 мм. Уменьшить ширину до 2400?» Пустой экран зовёт к действию: «Здесь будут проекты. Начните с замера помещения». Англицизмов и кодов ошибок нет.

## 9. Состояния

У каждого экрана четыре: **пусто** (рисунок линией чертежа + одна кнопка), **загрузка** (тонкая латунная полоса прогресса сверху, без спиннеров на весь экран), **ошибка** (что случилось + кнопка «Что делать»), **готово**. Кнопки: обычная, наведение (`--поверх-3`), нажатие (сдвиг на 1 px вниз), фокус (латунное кольцо 2 px с зазором 2 px), отключена (`--текст-3`, без тени).
