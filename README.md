# Кухня 3D — приложение

3D-конструктор кухни для Windows: комната, каталог модулей, сборка мышкой, сохранение проектов.
Первая рабочая версия (этапы 0–3 плана и часть 4–5).

## Что уже работает

- **Главное меню**: «Проект», «Проекты», «Открыть файл», «Пример кухни».
- **Комната**: длина, ширина, **высота стен** (потолка нет), толщина стен, обои и пол — палитры.
- **3D-окно**: два режима обзора — **«Сверху»** (наклонный вид) и **«Прогулка»** (стоишь в квартире, глаза 1,6 м).
- **Мышь**: **левая кнопка** — выбрать объект и таскать его по полу; **правая** — наклон и поворот камеры; **средняя** — сдвиг камеры; **колесо** — приближение. Стена, стоящая между камерой и комнатой, скрывается сама — видно, что внутри.
- **Клавиатура**: `WASD` — лететь, `Q`/`E` — вниз/вверх, `Shift` — быстрее, `V` — «Сверху / Прогулка», `Home` или кнопка **«Вся комната»** — показать комнату целиком, `G` / `R` / `T` — двигать / крутить / растянуть, `Ctrl+Z` / `Ctrl+Y` — отменить / вернуть, `Delete` — удалить, `Shift+клик` — выбрать несколько.
- **Конструктор**: 57 позиций — 14 шаблонов заказчика (KB281/KB160), свободный модуль, тумбы, навесные, столешницы, техника, мойка и вытяжка, столы и стулья, мягкая мебель, окна и двери, отделка. Поиск и категории.
- **Работа с объектом**: у выделенного модуля появляются **свои стрелки осей X (красная) / Y (зелёная) / Z (синяя)**. Что делает тяга за стрелку — зависит от инструмента внизу: «Двигать» перемещает по этой оси, «Растянуть» меняет размер по этой оси, «Крутить» вращает вокруг неё. Плюс можно просто тащить объект по полу левой кнопкой. `Shift+клик` — выбрать несколько, `Ctrl+D` — дублировать.
- **Точные размеры и повороты** (панель «Объект»): Ш/Г/В в миллиметрах, X, Z, высота подвеса, **поворот вокруг вертикали**, **наклон вперёд-назад** и **наклон влево-вправо** — в градусах, кнопки «⟲ 90° влево» / «90° вправо ⟳», кнопка «Вернуть стандартный размер».
- **Дверцы**: у каждого модуля можно выбрать **сторону петель** — слева, справа, сверху (открывается вверх) или снизу — и нажать **«Открыть дверцы»**, чтобы увидеть изделие открытым. Так тумбу с ручкой справа легко перевернуть в вариант с ручкой снизу.
- **Материалы**: палитра фасадов, обои и пол; цвет и материал хранятся в проекте.
- **Проекты**: сохраняются в папку `Проекты\` рядом с приложением (портативно), с превью; автосоздание бэкапов (20 последних) в `Бэкапы\`; «Открыть файл» и «Выгрузить .kitchen».
- **Смена курса заказчика учтена**: приложение — универсальный конструктор, 14 модулей это стартовые шаблоны.
- **Формат открыт для Claude**: `public/Библиотека/схема-проекта.md` — описание формата, `пример-проекта.kitchen` — рабочий пример. Проект можно написать руками и открыть.

## Как запустить

```powershell
# из папки приложения
npm install          # один раз
npm run dev          # режим разработки, http://127.0.0.1:5273/
npm run app          # десктопное окно (Electron), грузит собранный dist/
npm run build        # сборка в dist/
npm run dist         # инсталлятор и портативная сборка (electron-builder)
```

Проверка интерфейса (headless Chrome, скриншоты в `проверка\`):

```powershell
npm run dev                                  # в отдельном окне
node scripts/проверка-интерфейса.cjs
```

Сборка примера проекта для Claude:

```powershell
npx esbuild scripts/пример.ts --bundle --format=esm --platform=node --outfile=.tmp.mjs
node .tmp.mjs
```

## Структура кода

| Файл | Что внутри |
|---|---|
| `src/types.ts` | модель данных: проект, комната, объект, модуль. Все размеры в миллиметрах |
| `src/store.ts` | состояние приложения, действия, undo/redo, сохранение и загрузка |
| `src/lib/schema.ts` | проверка файла `.kitchen` (zod) с понятными ошибками по полям |
| `src/lib/storage.ts` | файлы через Electron или localStorage в браузере |
| `src/lib/демо.ts` | сборка примера кухни из каталога |
| `src/data/modules.ts` | каталог 57 модулей (здесь же 14 шаблонов заказчика) |
| `src/data/materials.ts` | обои, полы, фасады, столешницы |
| `src/three/Scene.tsx` | сцена: комната, камера, объекты, гизмо, сетка |
| `src/three/Furniture.tsx` | процедурная геометрия модуля по числам |
| `src/ui/Screens.tsx` | меню, список проектов, создание комнаты |
| `src/ui/Panels.tsx` | конструктор, свойства объекта, настройки комнаты, нижняя панель |
| `electron/main.cjs` | окно приложения, папка `Проекты\`, атомарная запись, бэкапы |

## Правила, которые нельзя нарушать при доработке

1. Логика размеров — в `src/lib` и `src/store.ts`, без three.js. 3D только рисует.
2. Все размеры в миллиметрах, целые. В метры переводятся только в 3D через `м()`.
3. Потолка нет — только `высота_стен`.
4. Числа 14 шаблонов заказчика берутся из `исходные-данные\модули-KB281-KB160.md` версии 1.1. При расхождении с чертежом прав чертёж.
5. Формат `.kitchen` документируется в `public/Библиотека/схема-проекта.md` — если меняешь схему, обнови документ и `schemaVersion`.
