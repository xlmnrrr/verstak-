# Верстак

Десктопный 3D-конструктор встроенной и корпусной мебели под размеры помещения (Windows, Electron + React + three.js). Замер, сборка в 3D, проверка размеров и норм, смета, деталировка и чертёж для цеха. Всё работает офлайн.

## Как скачать и установить
1. Открой вкладку **Releases** этого репозитория и скачай **`Верстак-0.1.0-установщик.exe`** (установщик, ярлыки на рабочем столе и в «Пуск») или **`Верстак-0.1.0-portable.exe`** (без установки: запускается откуда угодно, проекты лежат рядом с файлом).
2. Запусти файл. Windows может показать «Неизвестный издатель» (приложение не подписано): «Подробнее» → «Выполнить в любом случае».
3. Проекты и бэкапы хранятся в папках `Проекты\` и `Бэкапы\` рядом с программой; при удалении установщиком они не трогаются.

## Что внутри
- 141 изделие каталога настоящими моделями: шкафы, кухня, техника, мебель, свет, окна и двери, декор.
- Вступление при запуске (пропуск — Esc), «Идеи от Claude» на обложке, «Предложи планировку», проверка норм, смета с ценами мастера, чертёж PDF, экспорт XLSX/CSV/glTF.
- Три профиля качества: «Быстро», «Стандарт», «Фото».

## Запуск из исходников
Нужен Node.js 20+.
```bash
npm install
npm run dev        # откроется на http://127.0.0.1:5273 (лучше в Electron: npm run app)
npm test           # тесты
npm run build && npx electron-builder --win --x64   # сборка .exe в release\
```
