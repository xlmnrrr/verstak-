> Документ для того, кто пишет проект в блокноте (мастер, Claude, другой человек).
> Формат проверяется кодом `src/model/файл.ts`; что пример ниже открывается, проверяет тест `src/model/рукописный.test.ts`.
> Рядом лежат два образца: **`проект-руками.kitchen`** (написан руками, три предмета — точно этот пример) и `пример-проекта.kitchen` (демо-кухня, старый формат v1 — тоже открывается).

## 1. Правила за одну минуту

| Правило | Значение |
|---|---|
| Формат | обычный JSON в UTF-8, расширение `.kitchen` |
| Единицы | **миллиметры**, лучше целые |
| Оси | **X — вправо, Z — вниз по плану (к зрителю), Y — вверх от пола** |
| Позиция предмета | `[X, Y, Z]`: **X и Z — центр** предмета в плане, **Y — низ** предмета (у напольных 0) |
| Контур помещения | точки `[x, z]` **по часовой стрелке**, если смотреть сверху (как на плане: X вправо, Z вниз) |
| Поворот | градусы вокруг вертикали: `0` — фасад смотрит в **+Z** (от задней стены в комнату), `90` — в **−X**, `180` — в **−Z**, `270` — в **+X** |
| Цвет | `#rrggbb` или id материала из библиотеки (`дуб-натуральный`, `мрамор-калакатта`, `лдсп-белый-мат`…) |
| Лишние поля | не ломают файл: приложение их сохраняет и пишет обратно |

**Как поставить предмет вплотную к стене.** У прямоугольной комнаты с контуром от `[0, 0]`:
- к задней стене (Z = 0), фасад в комнату: `поворот 0`, `Z = глубина / 2`;
- к левой стене (X = 0): `поворот 270`, `X = глубина / 2`;
- к правой стене (X = ширина комнаты): `поворот 90`, `X = ширина − глубина / 2`;
- к передней стене (Z = длина): `поворот 180`, `Z = длина − глубина / 2`.

Модули в ряд вплотную: следующий X = предыдущий X + (ширина₁ + ширина₂) / 2.

## 2. Минимальный проект: спальня и три предмета

Скопируйте целиком в блокнот, сохраните как `Моя спальня.kitchen` и откройте: обложка → «Открыть файл» (или положите в папку `Проекты\` рядом с программой — проект появится в списке).

```json
{
  "schemaVersion": 2,
  "название": "Проект руками",
  "создан": "2026-11-12T10:00:00.000Z",
  "изменён": "2026-11-12T10:00:00.000Z",
  "помещения": [
    {
      "id": "п1",
      "тип": "спальня",
      "название": "Спальня",
      "контур": [[0, 0], [3600, 0], [3600, 3600], [0, 3600]],
      "высота": 2700,
      "толщина_стен": 100,
      "смещение": [0, 0],
      "отметки": [
        { "id": "дверь", "стена": 3, "вид": "дверь", "от_угла": 200, "от_пола": 0, "ширина": 800, "высота": 2000 }
      ],
      "отделка": { "стены": "#e6dccb", "пол": "#a07a55" }
    }
  ],
  "объекты": [
    {
      "id": "шкаф",
      "изделие": "шкаф-купе-1800",
      "помещение": "п1",
      "позиция": [900, 0, 300],
      "поворот": 0,
      "габариты": { "ш": 1800, "г": 600, "в": 2400 }
    },
    {
      "id": "комод",
      "изделие": "комод-900",
      "помещение": "п1",
      "позиция": [3150, 0, 225],
      "поворот": 0,
      "габариты": { "ш": 900, "г": 450, "в": 850 },
      "материалы": { "фасад": "дуб-натуральный" }
    },
    {
      "id": "кровать",
      "изделие": "кровать-1600",
      "помещение": "п1",
      "позиция": [1800, 0, 2570],
      "поворот": 180,
      "габариты": { "ш": 1600, "г": 2060, "в": 1000 }
    }
  ]
}
```

Что здесь важно:
- Шкаф 1800 × 600 у задней стены: X = 1800 / 2 = 900, Z = 600 / 2 = 300.
- Комод 900 × 450 в правом углу: X = 3600 − 900 / 2 = 3150, Z = 450 / 2 = 225.
- Кровать изголовьем к передней стене (`поворот 180`): Z = 3600 − 2060 / 2 = 2570. До шкафа в ногах 940 мм, по бокам по 1000 мм — норма 700 выполнена.
- Дверь на левой стене (стена 3) в 200 мм от её начала — от переднего угла; створка 800 не задевает кровать (до неё 1000 мм). **Стены прямоугольника:** 0 — задняя (слева направо), 1 — правая (сверху вниз), 2 — передняя (справа налево), 3 — левая (снизу вверх). `от_угла` считается от начала стены по этому обходу.
- `настройки` и `связи` можно не писать: подставятся значения по умолчанию.

## 3. Помещение — элемент массива `помещения`

| Поле | Тип | Обязательно | Смысл |
|---|---|---|---|
| `id` | строка | да | любой, на него ссылаются предметы (`"п1"`) |
| `тип` | строка | да | `кухня`, `спальня`, `гостиная`, `детская`, `кабинет`, `прихожая`, `гардеробная`, `ванная`, `санузел`, `коридор`, `кладовая`, `лоджия` |
| `название` | строка | да | подпись на вкладке |
| `контур` | `[[x, z], …]` | да | внутренний контур по часовой, не меньше 3 точек. Г- и П-образные — 6 и 8 точек |
| `высота` | число или `"неизвестна"` | да | высота стен, от 1000; `"неизвестна"` рисуется как 2700 с пометкой |
| `толщина_стен` | число | да | обычно 100–150 |
| `смещение` | `[x, z]` | да | где помещение на плане квартиры; у одного помещения `[0, 0]` |
| `отметки` | массив | да | двери, окна, розетки, вода… (может быть `[]`) |
| `отделка` | `{ "стены", "пол" }` | да | цвет или id материала (`стена-штукатурка-белая`, `паркет`…) |
| `метки` | массив строк | нет | `"уточнить"`, `"спорно:высота"` |

**Отметка на стене** (`отметки[]`): `id`, `стена` (номер ребра контура от 0), `вид`, `от_угла`, `от_пола`, `ширина`, `высота` — всё обязательно; `глубина`, `метки`, `заметка` — нет.

| `вид` | Что делает |
|---|---|
| `дверь`, `арка`, `окно` | вырез в стене; валидатор не даёт закрыть проём; у двери ещё `петля` (`"слева"`/`"справа"`), `открывание` (`"внутрь"`/`"наружу"`), `открыта` |
| `ниша` | углубление в стене (`глубина`); метка `"запретная-зона"` — нельзя закрывать |
| `короб` | выступ из стены (`глубина` по умолчанию 300): мебель строится вокруг |
| `радиатор` | у пола, `глубина` 100: «Предложи планировку» не ставит перед ним мебель |
| `щиток` | на кухне не закрывается мебелью, в шкафу — зона без задника и полок |
| `розетка`, `выключатель`, `вода`, `канализация`, `наличник` | отметки для расчёта: мойка — ближе к воде, за корпусом у розетки — вырез |

## 4. Предмет — элемент массива `объекты`

| Поле | Обязательно | Влияет на 3D | Смысл |
|---|---|---|---|
| `id` | да | — | уникальный в файле |
| `изделие` | да | **да** | id из таблицы ниже; незнакомый станет «свободным корпусом» с предупреждением |
| `помещение` | да | **да** | `id` помещения; если такого нет — предмет попадёт в первое |
| `позиция` | да | **да** | `[X центра, Y низа, Z центра]` |
| `поворот` | да | **да** | градусы, см. §1 |
| `габариты` | да | **да** | `{ "ш": ширина, "г": глубина, "в": высота }`; по ним строятся все детали |
| `раскладка` | нет | **да** | только отличия от изделия, см. ниже |
| `материалы` | нет | **да** (цвет) | `{ "корпус", "фасад", "столешница", "ручки", "стекло", "задник", "цоколь", "техника" }` |
| `открыт` / `открыто` | нет | **да** (поза) | `true` — открыто всё; `открыто: ["дверь-1"]` — отдельные створки |
| `угол_открывания` | нет | **да** | градусы распашных дверей (по умолчанию 100; конфликты считаются на 110) |
| `название` | нет | нет | своя подпись в списках и спецификации |
| `материал_описание` | нет | нет | словами для спецификации: `"ЛДСП 16 мм Egger"` |
| `метки` | нет | нет | пометки для себя (`"уточнить-высоту"`) |

**`раскладка` — отличия от изделия** (пишите только то, что меняете):
```json
"раскладка": {
  "корпус": { "плита": 18, "цоколь": 100, "задник": "ХДФ", "боковины": true },
  "фасад": { "тип": "распашной", "створок": 2, "петли": "справа", "ручка": { "вид": "скоба", "место": "верх" } },
  "секции": [
    { "ширина": "доля", "наполнение": { "направление": "снизу-вверх", "число": 0, "тип": "регулируемая", "штанга": { "высота": 1900 } } },
    { "ширина": 450, "наполнение": { "направление": "снизу-вверх", "число": "авто", "тип": "регулируемая", "ящики": { "число": 3, "высота": "авто" } } }
  ]
}
```
- `фасад.тип`: `нет`, `распашной`, `купе`, `ящики`, `подъёмник`, `push`, `зеркало`, `стекло`; `петли`: `слева`, `справа`, `попарно`, `сверху`, `снизу`.
- `секции` заменяют секции изделия целиком; `"доля"` делит остаток ширины поровну, число — мм. Сумма не должна быть шире корпуса (валидатор скажет, на сколько).
- `число` полок `"авто"` — шаг 320 мм, как в приложении.

## 6. Если файл не открылся

Приложение показывает ошибку с путём до поля, например:
- `помещения.0.контур: в контуре должно быть не меньше трёх точек`;
- `объекты.2.габариты.ш: Invalid input: expected number, received string` — число записано в кавычках;
- `Это не JSON: …` — лишняя или пропущенная запятая, кавычки-«ёлочки» вместо `"`.

Предупреждения файл не останавливают: «изделие не найдено — показано свободным корпусом», «контур задан против часовой стрелки», «отметка выходит за стену».

## 7. Нормы, по которым проверяет валидатор

| Что | Норма |
|---|---|
| Проход перед рядом | не меньше 900 мм; перед холодильником 1000, перед посудомойкой 1200 |
| Рабочий треугольник | стороны 1200–2100 мм, сумма 3000–6600 мм; в одну линию — между мойкой и плитой ≥ 400 |
| Рабочая поверхность | 850–900 мм от пола |
| Фартук | 550–600 мм от столешницы до низа навесных |
| Дверцы | открываются на 110° без упора в стену и соседей |
| У кровати | 700 мм с боков и в ногах |
| Диван — ТВ | 1800–3500 мм |
| Стол / сиденье | 750 / 450 мм |

## 8. Старый формат v1

Файлы со `"schemaVersion": 1` (комната длиной и шириной, поле `модуль` с id вроде `cabinet-sink-600`) по-прежнему открываются: приложение переводит их в v2 и до первой записи кладёт копию в `Бэкапы\<имя>.v1.kitchen`. Новые проекты пишите в v2.
